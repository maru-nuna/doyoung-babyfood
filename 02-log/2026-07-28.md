세정이 "계획과 다름" 표시 기능을 아예 없애달라고 요청해서 관련 코드를 전부 제거했다.

### "계획과 다름" 표시 기능 제거
- 범례의 "✎ 계획과 다름" 칩, 하단 안내문의 파란색 설명 문구 삭제
- 끼니 편집 모달의 "✎ 계획과 다름으로 표시" 체크박스 삭제
- 표 셀·오늘의 식단 캐러셀에서 계획과 다른 값을 파란색으로 강조하던 로직(`autoChangedForMeal`, `mealChanged`, `cell-changed`, `changed-item`, `tm-chg` 등) 전부 삭제
- `State.changedManual` 필드 제거 (기존 Supabase 데이터에 남아있는 값은 그냥 무시되며 삭제되지 않음)
- 신규 재료(노란색) 표시 기능은 그대로 유지
- Playwright로 로컬 서버 띄워서 범례·모달·저장 동작·모바일(375px) 레이아웃 확인, 콘솔 에러 없음 확인
