간식 입력이 베이스/토핑과 다르게 자유 텍스트라 일관성이 떨어지고, 신규 간식도 노란색으로 표시되지 않아 세정이 통일 요청.

### 간식 입력 방식을 다른 재료와 통일
- 끼니 편집 모달의 간식 입력란을 textarea(자유 텍스트)에서 베이스/토핑/알러지와 동일한 재료별 입력(이름+수량+단위, "+ 간식 재료 추가" 버튼)으로 교체
- 저장 형식도 다른 재료와 같은 "이름 수량단위 · 이름 수량단위" 텍스트로 통일(`날짜|s|snack` 키는 그대로 유지, 기존 자유 텍스트 값도 이름만 있는 항목으로 그대로 파싱돼 데이터 손실 없음)
- 간식 셀을 터치했을 때 기존처럼 바로 입력 가능하도록, 그날 간식이 비어있으면 빈 재료 행을 자동으로 하나 추가해 포커스

### 신규 간식 노란색 표시
- 표의 간식 행도 베이스/토핑처럼 재료 칩으로 렌더링하도록 변경(기존엔 텍스트 한 줄로만 표시)
- "새로 먹은 재료" 판정 로직에 간식을 포함시켜, 처음 먹는 재료면 베이스/토핑과 동일하게 노란색으로 강조
- 판정 기준은 재료 전역 공유 — 이미 토핑으로 먹어본 재료를 간식으로 줬을 때는 신규로 표시하지 않음(알러지 테스트 취지에 맞춰 "이 재료를 처음 먹었는지"를 기준으로 통일)

### 검증
- 정적 서버로 실제 렌더링 확인: 간식 셀이 재료 칩(이름+g)으로 표시되고, 과거 자유 텍스트로 저장된 간식("바나나")도 노란색 신규 표시가 정상 적용됨을 확인
- 끼니 편집 모달에서 간식 필드가 다른 재료와 동일한 입력 UI로 뜨는 것 확인
- 실제 Supabase에 쓰는 저장 액션은 건드리지 않고, 순수 변환 함수(itemsToText/parseItems)만 별도로 검증

## 상단 "새롭게 먹은 재료" 요약과 "오늘의 식단"에도 간식 반영
바로 위 변경 직후, 세정이 8/16에 새로 먹은 바나나(간식)가 상단 "새롭게 먹은 재료" 요약과 "오늘의 식단" 카드에는 빠져있는 걸 발견해서 두 화면도 같이 맞춤.

### 새롭게 먹은 재료 요약
- 판정 로직이 "그 끼니의 먹은 양(`날짜|끼니|eaten`)이 입력된 경우만" 포함하도록 되어 있었는데, 간식은 애초에 끼니 단위 먹은 양 필드가 없어서 조건을 항상 통과 못 하고 제외되고 있었음
- 간식(내부적으로 끼니 인덱스 's'로 구분)은 이 게이트를 건너뛰도록 예외 처리 — 간식 로그가 남아있는 것 자체가 실제로 준 근거이므로 별도 확인 불필요

### 오늘의 식단
- 지금까지 베이스/토핑/알러지만 보여주고 간식은 빠져있던 걸, 끼니 카드들 옆에 "간식" 카드를 하나 더 추가(간식 행이 있는 탭에서만, 기존 표 노출 기준과 동일)
- 간식 카드를 누르면 다른 끼니 카드처럼 "먹은 양" 입력이 아니라, 표의 간식 셀과 동일하게 간식 편집 화면이 열리도록 클릭 동작 분리

### 검증
- 헤드리스 브라우저로 확인: 94~148일 탭 상단 요약에 "바나나" 칩 노출, 오늘의 식단(8/16) 카드에 "간식 바나나 10g" 표시, 간식이 없는 날(8/17)은 "·"로 표시됨을 확인
- 오늘의 식단 간식 카드 클릭 시 간식 편집 팝업(바나나 10g 프리필)이 열리는 것 확인, 저장 없이 취소로 종료해 실제 데이터는 건드리지 않음
