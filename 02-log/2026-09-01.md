# 2026-09-01

큐브를 한 번에 여러 개 만드는 실사용 패턴에서 재료 창고가 불편하다는 피드백. 큐브 용량 상한, 조작 중 행 이동, 개수 증감 방식 세 가지를 손봄.

### 1큐브 용량 30g 추가
- 추가 폼·수정 폼 드롭다운 선택지에 30g 추가(기존 10/15/20g). 오트밀 등 베이스 곡물이 끼니당 30g이라 20g이 상한이면 부족했음.
- 큐브 그림 크기 매핑(`whMiniCubePx`)에 30g 크기(19px) 추가.

### 부족 재료 정렬 고정
- 그동안 매 렌더마다 "부족(3개 미만) 먼저"로 재정렬해서, +를 눌러 부족이 풀리는 순간 행이 아래로 뚝 내려갔음.
- 모달을 열 때 표시 순서를 한 번만 확정(`whOrderSnap`)하고, 열려 있는 동안 −/+·직접 입력으로는 순서를 안 바꾸게 변경.
- 창고를 닫았다 다시 열면 그때 새 순서로 재정렬. 재료 추가 시에도 스냅샷 갱신.

### 큐브 개수 직접 입력
- 개수 숫자(점선 밑줄)를 누르면 숫자 입력칸으로 바뀜. Enter로 저장, Esc로 취소, 포커스 벗어나면 저장.
- 기존 −/+ ±1 버튼은 그대로 유지(미세 조정용).

### 검증
- 로컬 서버 + Chrome(playwright-core, Supabase 호스트 차단해 실DB 미기록)으로 확인.
- 두 드롭다운 모두 10/15/20/30 노출, 부족 재료 +2 후에도 모달 열린 동안 위치 유지, 재오픈 시 재정렬, 숫자 직접 입력·Esc 취소 정상.
