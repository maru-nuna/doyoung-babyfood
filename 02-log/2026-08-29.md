# 2026-08-29

도영이 이유식에 재료 큐브 재고를 직접 관리하고, 일자별 식단 계획량만큼 큐브를 차감하며, 재고가 3개 미만이면 알려주는 기능을 추가했다. 재고가 떨어지는 걸 미리 알아채는 게 목표.

### 재료 창고

- 상태 구조에 `inventory` 추가: `{ items:[{id,name,cubeG,count}], deducted:{ "M/D":[{name,cubes}] } }`. `bbf_state.data`(jsonb)에 키만 추가, 스키마 변경 없음
- 처음엔 상단 메인 탭으로 뒀다가, 세정 요청으로 "재료 체크리스트" 버튼 옆의 "재료 창고" 버튼 → 모달로 변경
- "재료 테스트 체크리스트" 라벨을 "재료 체크리스트"로 변경(버튼·모달 제목)
- 재료 추가: 이름 + 1큐브 용량(10/15/20g) + 시작 큐브 개수. 같은 이름 중복 등록 차단
- 목록: 남은 개수만큼 재료별 색 큐브를 그림(당근 주황·소고기 갈색·채소 녹색 등, 미등록 재료는 이름 해시로 색 생성). 24개 초과분은 `+N개`로 축약
- 각 행에서 −/+ 로 큐브 개수 직접 증감(0에서 멈춤), 수정(이름·용량)·삭제 가능
- 보기 전용 모드(`?view=1`)에서는 버튼·모달 숨김

### 재료차감

- 주간 표 맨 아래 "재료차감" 행 추가. 날짜 칸마다 버튼
- 누르면 그 날 모든 끼니 + 간식의 계획량(g, override 반영)을 재료별로 합산 → `합산g ÷ 1큐브 용량`을 올림해 정수 큐브만 차감
- 창고에 없는 재료는 건너뜀
- 오늘·이후 날짜만 버튼 활성, 과거 날짜는 비활성
- 차감한 날은 "차감됨 ↩"로 바뀌고 다시 누르면 되돌림. 같은 날 중복 차감 방지

### 3개 미만 알람

- 앱 진입 시 헤더 아래 배너로 "재료 부족: OO N개" 표시, 누르면 재료 창고 모달 열림, X로 그 세션만 닫기
- 재료 창고 목록에서도 해당 행을 빨간 배경 + "⚠ 부족" 텍스트로 상시 표시(색만이 아니라 텍스트로도)

### 테스트 중 클라우드 오염

- 로컬 테스트가 실제 Supabase에 붙는 구조라, 테스트용 재료 데이터가 실제 `bbf_state` 행에 저장됨
- 세정 확인: 배포 사이트에서 실제 입력한 먹은 양·재료 체크·책 후기 데이터는 아직 없음 → 데이터 손실 아님
- 이후 테스트는 Supabase를 끈 사본으로 진행. 클라우드에 남은 테스트 재료는 `data - 'inventory'`로 제거 예정

## 끼니 상세 편집 모달 개편

### 토핑 → 채소 / 고기 분리

- "토핑" 필드를 "채소" / "고기" 두 필드로 나눔 (알러지·간식은 그대로)
- 모달 열 때 `CAT.meat`(소고기·닭고기·돼지고기·대구살) 기준으로 자동 분류
- 저장은 기존과 동일하게 `date|mi|top` override 하나로 합침(고기 → 채소 → 알러지 순), "변경 없음" 판정 기준 순서도 동일하게 맞춤

### 재료 칩 선택

- 채소·고기의 "+ 추가"를 누르면 재료 칩 트레이가 펼쳐짐. 칩을 누르면 기본 g로 행 추가, 이미 추가된 칩은 선택 표시, 다시 누르면 제거
- "+ 직접 입력" 칩으로 빈 행(직접 타이핑)도 가능
- 채소 칩 = `categories`의 채소 + 콩/두부류 + 해조류, 고기 칩 = 고기 + `CAT.meat`

### 기본값 조정

- 재료 추가 기본 g: 베이스 30, 채소 15, 고기 10 (기존 일괄 15에서 분리)
- 배죽: 이번 세션에 새로 추가한 베이스에만 기본값 4를 미리 채움. 기존 베이스·과거 데이터는 종전대로 빈값 유지
