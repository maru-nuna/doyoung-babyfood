# 2026-08-31

도영 이유식 기능 3가지 개선 요청. 고기 기본 분량이 늘어난 월령을 반영하지 못하고, 베이스만 칩 선택이 없어 입력 방식이 어긋나고, 재료차감을 쓰려면 매번 주간 표까지 내려가야 하는 불편을 해소하는 게 목표.

### 고기 기본값 20g

- 끼니 모달에서 고기 칩·직접 추가 시 기본값 10g → 20g (`DEF_G.meat`).
- 주간 표 고기 행 라벨 "고기(10g)" → "고기(20g)", g 배지 숨김 기준도 20으로 통일(세정 확인).
- 라벨 문구 "· 칩을 눌러 추가 (기본 10g)" → "20g".

### 베이스 칩 선택

- 베이스 필드도 채소·고기와 동일하게 "+ 베이스 추가" → 칩 트레이 토글 방식으로 전환.
- 칩 목록: 쌀·오트밀·현미·검은콩·퀴노아(고정 우선) + `categories`의 곡류/베이스 + 직접 추가한 곡류.
- 칩으로 넣고 빼면 배죽 입력란(`renderMealRatios`)도 같이 갱신.
- "+ 직접 입력" 칩으로 빈 행 입력도 유지.

### 오늘의 식단 재료차감 버튼

- "오늘의 식단" 카드 헤더 우측에 재료차감 버튼 추가.
- 보고 있는 슬라이드 날짜 기준으로 동작. 슬라이드를 넘기면 라벨("8/31 재료차감" / "8/31 차감됨 ↩")과 상태를 그 날짜로 갱신(`updateTodayDeductBtn`).
- 차감 로직은 주간 표 버튼과 공용(`applyDeduct`·`undoDeduct`).

### 검증

- 로컬 정적 서버로 확인: 베이스 칩 토글(현미 추가 시 30g·배죽행 추가), 고기 칩 추가 20g, 주간 표 라벨 "고기(20g)", 오늘의 식단 헤더 버튼이 8/31→9/1→9/2 슬라이드 따라 라벨·상태 갱신, 끝에서 오늘로 루핑 시에도 정상.
- 모바일(375px) 레이아웃에서 헤더 버튼이 카드 밖으로 튀지 않고 가로 스크롤 없음.
- 실 Supabase에 쓰는 저장·차감 액션은 실행하지 않고 UI 동작만 확인.
