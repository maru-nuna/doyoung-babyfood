세정이 8/18~23 끼니에서 검은콩을 일괄 삭제해달라고 요청했고, 이어서 같은 날 3끼 전환일을 8/16로 앞당겨달라고 요청했다.

### 8/18~23 검은콩 제외 (이후 3끼 전환으로 대체됨)
- 8/8~9/11 고정 식단(FIXED_MEAL_AM/PM) 로직에 8/10~16 두부 제외 예외와 같은 방식으로 날짜 범위 조건 추가
- 검은콩은 대체 없이 그대로 빼서 총량이 15g씩 줄어듦(1끼 195→180g, 2끼 190→175g)
- 곧이어 3끼 전환일이 8/16으로 당겨지면서 8/18~23이 통째로 3끼 탭으로 넘어가, 이 예외 로직은 불필요해져 제거함

### 3끼 전환일을 9/12 → 8/16으로 앞당김
- 2끼 고정 식단(FIXED_MEAL_END)을 9/11→8/15로 단축, 3끼 탭(tab4) 시작을 9/12→8/16으로 조정
- n일차·dday 카운터는 날짜 기준으로 계속 이어지므로 탭 경계만 이동(60~93일 / 94~148일로 라벨·범위 재계산, 최종 종료일 10/9·148일차는 그대로 유지)
- 탭 라벨 "60~120일"→"60~93일", "121~148일"→"94~148일"

### 8/16~8/30 새 3끼 식단 자동 생성
- 세정 요청 구성: 베이스 90g(쌀30·오트밀30·퀴노아30, 3끼 공통) + 채소 5종×20g(100g, 3끼 공통) + 단백질 10g(끼니별로 다름) = 끼니당 200g
- 단백질: 1끼 소고기10g · 2끼 돼지고기10g · 3끼 닭고기10g(수·토는 흰살생선 10g으로 대체) — 돼지고기는 세정이 이미 따로 먹여본 재료라 이번에 정식 도입
- 채소는 3일 간격으로 두 세트 교대(8/16=세트1 시작): 세트1(브로콜리·당근·연근·양배추·완두콩) / 세트2(케일·단호박·감자·콜리플라워·아스파라거스)
- 요일 판정은 기존 규칙과 동일하게 실제 달력 연도(SCHEDULE_YEAR) 기준
- 8/31 이후는 세정 요청대로 우선 빈 칸으로 남겨둠(추후 갱신)
- 체크리스트 재료 목록에 빠져 있던 "케일" 추가(나머지 신규 재료는 이미 목록에 있었음)

### 재료 수정 팝업 기본값 변경
- 끼니 상세 화면에서 새 재료를 추가할 때 기본으로 들어가던 g값을 15→20으로 변경(베이스 재료는 기존처럼 기본값 없음)
