7/10부터 메뉴가 비어있던 걸 채워 넣는 김에 기존 tab 경계도 다시 정리했다. 후기 이유식(60~87일) 구간은 세정이 정한 신규 재료·알러지 테스트 규칙에 맞춰 자동 생성되도록 만들었고, 세정이 여러 차례 짚어준 문제를 그때그때 수정했다.

### 탭 경계 조정
- 7/12까지 2끼 유지 결정에 따라 29~56일 탭(t2)이 7/10~7/12(57~59일차)를 포함하도록 확장 → 탭 라벨 "29~59일"
- 57~84일 탭(t3) 시작일을 7/10 → 7/13(60일차)으로 밀림 → 탭 라벨 "60~87일"
- 85~112일 탭(t4, 3끼) 시작일을 8/7 → 8/10(88일차)으로 밀림 → 탭 라벨 "88~115일"
- 옮겨진 7/10~7/12 식단은 기존과 동일하게 빈 칸(미입력) 상태로 이동, 내용 손실 없음

### 7/10~7/12 메뉴 채우기
- 7/9 메뉴(베이스·토핑·5/6/5 배죽 비율)를 그대로 복제

### 7/13~8/9(60~87일) 신규 재료 도입 스케줄
- buildTab3()을 신규재료·알러지 스케줄 자동 생성 로직으로 교체
- 신규 재료(계란 포함)는 서로 3일 이상 간격 + 평일에만 도입: 당근(7/13)→흰살생선(7/16, 고기)→계란노른자 알러지테스트(7/20)→새송이버섯(7/23)→토마토(7/27)→무(7/30)→검은콩(8/3, 베이스용)
- 돼지고기를 처음엔 소고기·닭고기와 같이 "이미 안전한 재료"로 넣었는데, 실제로는 기존 계획(NEWSEQ)상 7/12 도입 예정이었다가 그 전 탭이 7/9까지만 생성돼서 테스트된 적이 없었음(세정 1차 지적)
- 이후 세정이 아직 돼지고기를 넣지 말라고 해서 이번 구간에서 완전히 제외(추후 별도 요청 시 추가)
- 최초 버전은 계란 테스트를 7/17에 넣어 흰살생선 도입일과 하루 차이로 겹쳤던 문제를 3일 이상 간격 규칙에 맞게 수정
- 신규 재료는 도입일 1끼(아침)에만 넣고 2끼는 기존 로테이션 재료로 대체, 다음날부터 양쪽 끼니 로테이션에 정식 합류(세정 지적으로 수정 — 처음엔 도입일에 양쪽 끼니에 다 넣고 있었음)
- 채소 목록에서 청경채를 빼고 양파로 대체(세정 요청)
- 흰살생선은 채소가 아니라 고기(단백질) 카테고리로 분류돼 있음을 재확인

### 끼니 구성·총량 조정
- 고기가 매일 바뀌던 걸 1주일 단위 고정으로 변경 — 이번 주 1끼용 고기 1종·2끼용 고기 1종을 정해서 그 주 내내 유지, 신규 고기가 안전해지면 다음 주부터 조합에 합류(세정 지적으로 수정)
- 채소도 매일 바뀌고 있던 걸 세정이 다시 확인해서, 고기와 동일하게 1주일 단위로 6종을 고정하도록 수정(처음 수정 때 채소 쪽은 빠뜨렸었음)
- 검은콩 도입 이후 베이스 셋째 곡물은 현미·검은콩 격일 교대
- 끼니 총량을 175g(기존 실제 식사량) 기준으로 재조정 — 채소를 3종(45g)에서 6종(90g)으로 늘려 1끼 185g·2끼 175g으로 맞춤(세정 지적으로 수정 — 초안은 135~145g으로 기존보다 적었음)
- 쌀·현미·오트밀 배죽은 7/13~8/9 전체 5배죽으로 통일(마이그레이션 함수 추가)

### 간식 행 제거 (29~59일 탭)
- 29~59일 탭(t2)은 간식을 안 줘서 표에서 간식 행 자체를 뺌(세정 요청) — 60~87일·88~115일 탭은 그대로 유지

### 퀴노아·당근 스케줄 재조정
- 세정이 실제 Supabase 운영 데이터를 확인해달라고 해서 조회했는데, 저장된 override·log가 0건이라 "토핑에 넣은 퀴노아"는 서버에 반영이 안 된 상태였음(동기화 여부 재확인 필요, 세정에게 안내)
- 퀴노아는 7/7(tab2 구간)에 이미 먹어본 재료라는 걸 확인해서, 8/6 격리 테스트 없이 7/13(tab3 시작일)부터 바로 넷째 베이스로 상시 포함하도록 변경 — 그 결과 총량이 7/13부터 끼니당 15g씩 늘어남(1끼 200g·2끼 190g, 세정에게 안내)
- 당근도 7/13 하루만 격리 테스트하고 사라지던 걸, 1주차(7/13~19) 내내 채소 목록에 포함하도록 변경(세정 요청 — 한 번 확인되면 그 주는 계속 먹임). 양파는 원래도 매일 포함돼 있어서 변경 없음

### 실제 운영 데이터 수정 (퀴노아 토핑→베이스)
- 세정이 "7/7 1끼 채소2에 퀴노아가 있다"고 알려줘서 Supabase를 다시 조회해보니, 그 사이 동기화가 완료돼 있었고 7/7~7/16 사이 17개 끼니에 퀴노아가 토핑으로 저장돼 있었음
- 해당 17건 전부 토핑에서 퀴노아를 빼고 베이스에 추가(다른 재료·먹은 양 기록 등은 그대로 유지) — Supabase REST API로 직접 override 수정 후 재조회로 반영 확인

### 1주차(7/13~19) 현미 제거·고구마 추가
- 1주차만 현미를 아예 안 쓰도록 변경(세정 요청) — 베이스가 쌀+오트밀+퀴노아만 남아 75g, 현미 제거분(-15g)만큼 총량이 다시 185g·175g으로 돌아옴
